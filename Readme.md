# Price Discovery Service for T100C

## Overview
Real-time price discovery for T100C asset With Trading Chart.

## 🚀 Features
- Real-time price data streaming
- WebSocket server implementation
- RESTful API endpoints
- Database integration
- Asset price monitoring


## 🛠 Technology Stack
- Rust
- WebSocket
- PostgreSQL
- RESTful APIs



## 🔧 Setup & Installation

### Prerequisites
- Rust (latest stable version)
- PostgreSQL


### Local Setup
1. Clone the repository
```bash
git clone https://github.com/yourusername/avo100-backend.git
cd avo100-backend
```

2. Run The Program 

```shell
cargo build
# After Run
cargo run
```
